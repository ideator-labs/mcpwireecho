Build McpWireEcho: a self-proving MCP protocol-version dialect probe.

CLAIM: Offering protocolVersion 2026-07-28 classifies a target as old_only, echo_negotiator, or discover_ok. A server that echoes the requested version is not the same as one that implements server/discover.

DATA SHAPE (name these first, before logic):
- DialectClass = "old_only" | "echo_negotiator" | "discover_ok"
- ProbeReport: { target, class, offeredVersion, initializeEcho?, discover: {ok|errorCode}, evidence[] }
- Three fixture server behaviors (in-process fakes, no network required):
  1) old_only: initialize returns protocolVersion 2025-06-18; server/discover returns JSON-RPC -32601
  2) echo_negotiator: initialize/meta echoes whatever protocolVersion was offered (including 2026-07-28); server/discover still -32601
  3) discover_ok: server/discover returns DiscoverResult with supportedVersions including 2026-07-28

DEMO (the real artifact):
- bash demo.sh
- Probes all three fakes, prints PATH A/B/C PASS or FAIL with clear before/after
- Writes report.json (or per-target reports)
- Exit 0 only if all three classifications match expected
- Exit non-zero if any class drifts
- Break one fixture on purpose once during development to confirm demo fails, then restore
